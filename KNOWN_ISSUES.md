# Known Issues

This page lists confirmed user-facing issues that are still open or worth documenting.

## Current known issues

No major known issue is currently documented for `0.10.27-beta`.

## How an issue gets listed here

An issue may be added when it is:

- reproducible
- confirmed by the maintainer
- relevant to multiple users
- not yet fixed in the current public version

## Status labels

Recommended wording:

```text
Investigating
Confirmed
Workaround available
Fix planned
Fixed in next release
```

## Reporting a new issue

Use the public GitHub **Bug report** template.

Do not include private session links, credentials or personal data.
