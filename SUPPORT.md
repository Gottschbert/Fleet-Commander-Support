# Fleet Commander Support Guide

## Before reporting a bug

Please try:

1. Reload Fleet Commander.
2. Perform a hard refresh.
3. Confirm the displayed Fleet Commander version.
4. Check whether the issue still occurs.
5. If possible, test in another browser.
6. Take a screenshot if the problem is visual.

## Useful information for a bug report

Please provide:

```text
Fleet Commander version:
Browser:
Browser version:
Operating system:
Device:
Desktop / Tablet / Mobile:

Steps:
1.
2.
3.

Expected:
Actual:
```

## Problems with shared sessions

If a shared session fails:

- do not publish the full private session URL in a public Issue
- state whether it was a short `/join/...` link or a long encrypted link
- state the browser/device
- state the error message shown
- if needed, provide sensitive details to the maintainer through a private channel

## Problems with Fleet Overview

Useful information:

- ship name
- displayed status
- displayed `[CREW x/y]`
- assigned roles
- screenshot of the affected Fleet Tree section

## Problems with Pilot / Open Stations calculations

Please include:

- affected ships
- assigned crew/roles
- displayed Operational count
- displayed Pilots count
- displayed Open Stations count

## Feature requests

A good feature request answers:

1. What problem occurs during an actual fleet operation?
2. Who is affected?
3. How is it currently handled?
4. What should Fleet Commander do instead?
5. Is this required for planning, live operation, or post-operation work?
