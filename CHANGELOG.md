# Fleet Commander – Public Changelog

This changelog intentionally focuses on user-visible changes. Internal implementation details remain in the private development repository.

## 0.10.27-beta — 2026-08-10

### Improved

- Completely revised DE/EN User Guide.
- Added a clear Quick Start workflow for first-time users.
- Explained Operational, Pilots, Open Stations and Crew capacity indicators.
- Clarified the difference between Ship Stations and Mission Roles.
- Improved documentation of Save & Share, Discord Share and reset functions.

## 0.10.26-beta — 2026-08-10

### Improved

- Improved Fleet Overview station alignment.
- Large ship station lists are easier to read.
- Reduced unnecessary horizontal scrolling.

## 0.10.25-beta — 2026-08-10

### Improved

- Large station profiles can now use an adaptive two-line layout.
- Small ships remain compact in Fleet Overview.

## 0.10.24-beta — 2026-08-10

### Fixed

- Corrected Pilot and Open Stations values after the central ship database finishes loading.
- Fleet Overview and Dashboard now use synchronized operational data.

## 0.10.23-beta — 2026-08-10

### Improved

- More consistent action buttons.
- Dashboard KPIs now focus on Operational ships, Pilots and Open Stations.
- Improved Mission Readiness readability.
- Improved German player-status terminology.

## 0.10.22-beta — 2026-08-10

### Fixed

- Sample-data cleanup no longer removes protected ALPHA/BETA squadron structures.
- Expanded fallback role availability when no detailed ship profile is available.

## 0.10.21-beta — 2026-08-10
